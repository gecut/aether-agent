A few useful details

Before you settle in.

Is Aether Code open source?

Yes. The project is MIT licensed. You can inspect the code, report a problem, or contribute on GitHub.

Does it include the VS Code workbench?

The full IDE uses Code-OSS through code-server. Setup downloads a verified runtime. Compatible extensions come from Open VSX or VSIX files; Microsoft-only extensions and universal Marketplace compatibility are not guaranteed.

Do I need a provider account?

Agent features need a configured provider and access to the model you select. Provider availability and account eligibility vary. See the provider documentation for current support.

Where does my project live?

Your workspace stays in a local folder. Approved coding runs use separate Git worktrees. Review is required before applying their changes to your original project.
