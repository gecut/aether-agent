# Reference research and adoption decisions

Checked 2026-10-17 using GitHub API metadata, upstream READMEs, file trees and selected source; official provider docs were opened separately. This is the historical initial architecture research. Later adoptions are recorded in [Nexload integration](NEXLOAD_PROMPT_CORE.md), [Ava companion](COMPANION.md), and [third-party notices](../../THIRD_PARTY_NOTICES.md); those records supersede the initial adoption decisions below.

| Reference                                                               | Observed scope / selected source                                                                                                   | License observed                                         | Decision                                                                                                         |
| ----------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------- | -------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------- |
| [Hermes Agent](https://github.com/nousresearch/hermes-agent)            | Persistent sessions and reusable skills; `acp_adapter/session.py`, `gateway_session_meta.py`                                       | MIT                                                      | Use durable session metadata and inspectable knowledge as design principles; do not embed its Python runtime     |
| [Nexload SDK](https://github.com/gecut/nexload-sdk)                     | Current README documents health/observability and Payload CMS packages; selected logger JSON renderer and package layout inspected | GitHub metadata reported no recognized top-level license | Not an agent SDK. No dependency/source adoption; specific package licensing would need review before use         |
| [Archify](https://github.com/tt-a1i/archify)                            | Agent skill and interactive diagram viewer; viewer layout/source and review/tuning procedures inspected                            | MIT                                                      | Render an original task DAG from actual persisted dependencies; no copied viewer/assets                          |
| [Happy](https://github.com/slopus/happy)                                | Multi-harness CLI/mobile architecture; `packages/happy-cli/src/agent/acp/AcpSessionManager.ts` and diff layout paths inspected     | MIT                                                      | Preserve provider boundary and session lifecycle rather than adopting a remote sync service                      |
| [Loop Engineering](https://github.com/cobusgreyling/loop-engineering)   | Report-first bounded feedback loops and constraints; budget/install skill procedures inspected as data                             | MIT                                                      | Implement bounded retries, real verification evidence and approval gates; no autonomous policy rewriting         |
| [Omnigent](https://github.com/omnigent-ai/omnigent)                     | Meta-harness/provider isolation; ACP/Antigravity executor source paths and native-vs-SDK distinction inspected                     | Apache-2.0                                               | Keep transport differences explicit. Do not adopt private desktop RPC or claim missing runtimes work             |
| [OpenCode (linked repository)](https://github.com/opencode-ai/opencode) | Archived and points to Crush; Go provider and generated SQLite session source inspected                                            | MIT                                                      | Do not adopt an archived harness. Use its provider/session separation only as a design reference                 |
| [Vibe Coder Kit](https://github.com/omergocmen/vibe-coder-kit)          | Markdown personas, workflows and process rules; architecture review/brainstorm procedures inspected                                | MIT                                                      | Support reviewed local Markdown procedures with explicit scopes; no imported procedure gains execution authority |

Official interfaces: [Codex noninteractive mode](https://developers.openai.com/codex/noninteractive/), [Codex platform integration choices](https://developers.openai.com/blog/codex-as-a-platform), [Claude programmatic mode](https://code.claude.com/docs/en/headless), [Antigravity home](https://www.antigravity.google/docs/home), [Antigravity headless](https://www.antigravity.google/docs/cli/headless). Antigravity's documented `agy` pathway exists in current docs; the local binary and intended “3.8” identifier were not available to demonstrate it here.

The original product identity uses neutral charcoal surfaces, blue functional accents, a structured session workspace and explicit inspector. No proprietary Antigravity branding or assets are copied. License metadata is a preliminary review, not permission to copy an entire project; dependencies adopted later require their exact revision/license/NOTICE to be recorded.
