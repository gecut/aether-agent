# Live repository graph and text direction

Open **Graphify** in navigation or a session's Graphify tab. Nodes and relationships come from the installed local Graphify CLI. In a session the source follows the first running task worktree, then its integration worktree; the toolbar identifies the source. With concurrent tasks this displays one active worktree at a time, rather than merging conflicting files. Without a session it indexes the selected project. Empty projects display an empty state until source exists. Node colors describe approved task scopes, not proof that a specific symbol changed.

Live refresh checks Git's tracked/unignored source index every four seconds while the view is open. Metadata signatures cache unchanged extraction. Pause Live for a fixed view; Refresh graph forces reindexing. Source staging lives under application userData and is removed after extraction. Extraction accepts at most 1,000 source files, 500 KB per file and 20 MB total, excludes sensitive paths and symlinks, and never runs project code. Graph JSON is validated and capped at 2,000 nodes and 5,000 edges; the view displays up to 150 matching nodes. Search narrows the visible nodes. Select a node to inspect its file, location and connected relationships. Errors identify a missing CLI or failed extraction rather than showing synthetic data. Graphify remains an optional external CLI dependency; it is not bundled in the app.

On macOS, a translated Aether process can launch a universal Python interpreter in Intel mode while Graphify's parser libraries are arm64 (or the reverse). Aether detects this specific loader error and retries extraction once with `/usr/bin/arch` selecting the architecture reported by the installed parser. It remembers a successful selection for that CLI path. Other errors and other operating systems do not trigger this retry. Arguments remain separate, extraction remains code-only, and normal timeout/cancellation controls still apply.

If the runtime still cannot load, the graph shows an architecture repair message. Reinstall Graphify using a Python interpreter matching its parser libraries, for example `uv tool install --reinstall --python /opt/homebrew/bin/python3 graphifyy` on an Apple Silicon Homebrew installation, then choose **Refresh graph**. This also clears the cached failure for unchanged source. Aether does not automatically install or replace external runtimes.

Architecture regression verification: 99 automated tests passed; real Graphify 0.9.78 extraction succeeded from an Intel-emulated parent using native arm64 Python. Desktop E2E and live UI checks confirmed actual symbols, cached reads, live edits and graph search/selection in isolated fixtures.

Persian and Arabic use the bundled Vazirmatn variable font v33.003. Latin characters retain the app's system/Geist face. Prose uses automatic base direction and paragraph isolation, so Persian/Arabic paragraphs align right and English paragraphs align left. Code, diffs, file paths and identifiers retain LTR direction. The application navigation remains English. The font's source and complete SIL Open Font License are in THIRD_PARTY_NOTICES.md.

Verification: `npm test`, `npm run test:e2e`, `npm run test:live-ui`, and `npm run test:provider`. The live UI fixture uses a local deterministic HTTP planner only for UI approval checks; the provider smoke uses actual Codex in a separate temporary project. Neither executes the user's saved project objective.
