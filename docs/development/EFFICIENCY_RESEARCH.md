# Context efficiency and model discovery

Research and local verification: 18 October 2026. The sources below were reviewed through web search, official documentation and GitHub. Savings are measured on local fixtures; they are not a promise of lower subscription fees, provider billing, or unchanged answer quality.

These are component budgets, not the full request size or a provider context-window guarantee. Instructions, acceptance criteria, the current user request, and bounded diff data are added separately. The compiler's overall estimated-token limit still applies. New runs snapshot their settings; chat uses the current context mode.

## Measurements

`npm run benchmark` uses synthetic data, not user history. On the same 41-message fixture, the previous twelve-message policy sent 23,195 estimated history tokens; Economy sent 4,270, an **82% reduction against the previous policy**. Sending all 41 messages would use 84,309 estimated tokens, so the reduction against full history is approximately 95%. Economy retained the latest request, explicitly omitted 38 earlier messages, and preserved all 41 stored messages. Token estimates use UTF-8 bytes / 3, not a model tokenizer. This deliberately long fixture does not establish equivalent answer quality.

A repetitive test log shrank from 10,039 bytes to 99 bytes while retaining its distinct failure and source location. This extreme repetition fixture is not a representative compression percentage for arbitrary logs.

The existing 75-file source fixture remains 1,907 estimated context tokens, includes the assigned function and ancestor rules, and retrieves in about 10 ms. Streaming 500 output chunks still exports the database nine times and restores all 501 events. Results vary by machine; see [performance](PERFORMANCE.md) for the historical comparison and reproduction.

The installed Codex catalog returned seven models with supported reasoning levels in 271 ms without an inference request. Claude Code is absent on this machine; its aliases are shown as unavailable here. Antigravity discovery is bounded to ten seconds and may fail for an ineligible account/location. Catalog presence never proves entitlement or execution capability. Exact model ID entry remains available for installed providers that support the selected role.

## Desktop work

The full Code-OSS runtime downloads and starts only when requested. Returning to Aether hides its native view and preserves open editors/terminals for the next visit; it does not kill a user's terminal job. Quit stops the runtime. The quick editor remains a lazy local Monaco option. Model discovery no longer blocks startup on `agy models`.

Ava pauses off-screen or hidden animation, and paused chat avatars do not attach pointer listeners. The visible desktop widget samples the system cursor at 20 Hz, sends only changed coordinates, and stops polling when hidden. Cursor coordinates are neither stored nor sent to providers.
